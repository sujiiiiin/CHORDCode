## 当前场景与适用范围

垫子采用现有高度场体积化算法，共 4763 个粒子。猫绕 X 轴旋转 180°，按指定轨迹运动。底面 `y=0.18`，初始间隙 `0.01`，下压行程 `0.12`；等待、下压、保持、撤回分别为 `0.25 / 1.25 / 0.25 / 0.833333 s`，总时长 `3 s`。

上述摆放与运动属于当前场景，换场景时单独定义。超参数作为后续 video + physics 实验的起点；更换坐标尺度、几何或粒子表示时需重新检查适用性，不能直接当作真实物体的 SI 标定参数。
